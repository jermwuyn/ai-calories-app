# v0.1.0 — Backend & Nutrition API

Prepared release notes; no GitHub release has been published by this task.

- Self-contained 310-class EfficientNet-B0 inference, unchanged `unified-food-4-v2` ordering.
- Portable FastAPI settings, configurable CORS and explicit missing-model errors.
- Versioned nutrition seed: 88 ingredients, 1,668 values, 21 categories, 77 foods,
  77 profiles, 80 component links and 77 canonical mappings; source URLs retained.
- Additive profile metadata distinguishes 76 prepared-food references from the
  existing Cơm tấm ingredient recipe. Missing nutrients remain null.
- Safe, repeatable setup, checksum validation, frontend guide, typed API client,
  captured examples and exported OpenAPI.

## Maintainer release steps

1. Review and commit the intended source files, including the seed exception in
   `.gitignore`. Preserve the existing reviewed-import work. Do not add `.env`,
   the live nutrition database, checkpoints, datasets, environments or backups.
2. Create GitHub Release tag `v0.1.0` named **v0.1.0 — Backend & Nutrition API**
   after source review. This task does not push, tag or publish.
3. Upload the existing `checkpoints/best.pth` (64,354,977 bytes) as **best.pth**.
   Also attach `release/SHA256SUMS` and `release/model.json` for provenance.
   The seed is already in Git; it may optionally be attached under
   `nutrition-v0.1.0.sqlite3` to match SHA256SUMS.
4. Verify the public asset URL in `release/model.json` and execute setup from a
   clean clone without `--checkpoint-file`. See `docs/verification.md`.

Checkpoint SHA-256:
`48046928db30c2fcd4daf78f4a677b10ed37d08ba0cf82dd17a17266ef49de11`

Consumers use Python 3.11 and `python scripts/setup.py`, then
`python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000`.
For a separately downloaded release asset, use
`python scripts/setup.py --checkpoint-file /path/to/best.pth`.
An existing database is preserved unless `--overwrite-database` is supplied;
explicit restoration creates a backup first. No USDA account is required.

Known limitations: only 77 mapped profiles; no automatic portion estimation;
uncalibrated predictions; 76 reference foods are not ingredient recipes;
the Cơm tấm recipe remains labeled as a test recipe. Training data is excluded.
Model/dataset provenance is described in README; packaging does not establish
redistribution rights. Public release-download verification remains pending upload.
