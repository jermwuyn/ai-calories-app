# AI Calories

AI-powered food recognition and nutrition tracking application.

## Architecture
- Food Recognition: EfficientNet-B0
- Ingredient Nutrition Database
- Recipe Database
- Nutrition Calculator
- Backend: FastAPI
- Frontend: To be developed

## Project Structure
- backend/
- frontend/
- docs/
- tests/

## Development Status
Initial project setup.

## Goal
Recognize food from images, suggest ingredients and serving sizes,
and calculate nutritional information with user-editable portions.
